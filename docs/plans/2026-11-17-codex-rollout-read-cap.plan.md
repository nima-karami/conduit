## Architecture fixes

Use the reviewed shape of a single opened-stream iterator. Start conveys opened regular-file identity and fixed safe-integer high-water. Each following ordered lines/gap event carries absolute consumed cursor and discard status. End is mandatory even for zero change or incomplete below-cap data. A normal incomplete record leaves its cursor at start. It does not cause a self-retry; only an existing folder event/pending read does. Gap is emitted at entry to skipping (before the delimiter can arrive) and advances cursor. Final safe partial discarding state carries to the next read.

Initial scheduler replay has no incremental side effects. Accumulate only its existing reset-info, limit and resume state; on every gap clear all three conclusions since a missing record might change them. Later supported rows can establish a new conclusion. Publish the final end-only scheduler result on a successful logical end; on read failure retain prior scheduler cursor/replay state. Appends to active scheduler can deliver bounded batches in order. Commit cursor of a verified batch before callbacks so a subsequent read exception cannot replay delivered events or this batch's attempted callbacks. Guard exact tracked object and same bound path before each callback and halt stale user state on retirement. Keep disposition that ordinary valid records deliver the same scheduling effects; don’t synthesize a signal from a gap or malformed unsupported record.

For posture only, require the opened regular descriptor's safe positive inode/dev and known meta ID, reject new Link while any logical read is active, and keep prior linked state during a read until completed publication. Roll all new limited posture facts privately then emit once on successful logical end. Gap makes the current reading unknown/stale and keeps actual last-known report; later supported same-file data can restore. Read failure or short read marks stale, and a mismatched replacement invalidates linkage. Before publishing every valid batch under a known inode, and before final posture publication, check the current path still names the exact regular file and its size accommodates observed cursor/high-water. Make read cancellation retire before awaiting, no stale callback, and close the iterator in finally. Endpoint with unreliable inode continues ordinary regular-file scheduler reads, but cannot link or publish posture. Do not claim OS-level immutable path after an observation.

The rejection limit concerns a single record/physical read and never allocates according to the total tail. Preserve readable valid multi-chunk initial and live archives. Actual observable tests must exercise a skipped resume that cannot revive an old limit, a sustained no-complete-line tail without busy retry, final partial live batch error with no duplicate, in-flight link/retirement, read cancellation/close, replacement/truncation and Windows normal file compatibility. Check both identity and offset cases explicitly.
