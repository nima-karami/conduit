# CON-21 learnings

- [implementation-plan] fallow's dead-code check fails on exported symbols with no consumer, and test files count as entry points. A "pure modules first" slice therefore leaves intermediate merges red on unused exports until the consumer lands. Plan the contract types in the same lane as their first consumer, or expect the transient.
- [build-and-verify] Git identity isn't configured here. A bare `git merge --no-ff` fails with "Committer identity unknown", and a verify chained after it then runs on the unmerged tree. Use the `merge-verify.sh` helper (identity flags + per-merge verify ledger).
- [build-and-verify] Repo-wide guard tests (`hc-network-guard`, the tool-schema keyword whitelist) only fire in the full suite, so a lane's named check misses them. Lane briefs that add tool schemas or new string literals should name `npx vitest run test/unit/hc-network-guard.test.ts test/unit/conduit-mcp-control-tools.test.ts` as part of the check.
- [build-and-verify] Parallel UI lanes that each append CSS to the end of `webview/styles.css` break `test/unit/state-vocabulary.test.ts`: the interaction-state vocabulary must stay the last section. Brief CSS lanes to insert their block *before* `═ interaction state vocabulary`. Hand-resolving the append conflict dropped a closing brace twice; re-run biome and the vocabulary test after every CSS conflict.
- [build-and-verify] A lane brief that says "stop if a string is missing" stalls every UI lane on the first missing label. Give each lane its own namespaced key block in the shared strings file up front.
- [runtime-qa] Write e2e selectors from the rendered DOM, not from a lane's report of class names: two `requests-ui` runs were spent on wrong targets (`.reqtpl-title` vs `.reqtpl-head__title`, a Send wrapper vs `.reqtpl-send__btn`). Grep the component for the exact className and role before writing the locator, and assert an attribute on the element you click.
- [build-and-verify] /tmp is a 15 GB tmpfs with a per-user quota shared by every session. 28 lane worktrees plus downloaded e2e artifacts reached 1.1 GB, and a full /tmp makes verify and e2e fail in ways that look like code failures. Remove each lane's worktree (and branch) right after its merge, and delete downloaded e2e artifacts once the needed shots are copied.
