Date: 2026-10-26. Spec: [Role brief at launch](../../specs/2026-10-26-conduit-role-brief.md), §§2.1 and 12.

`--` preserved the initial prompt for all three measured CLIs. Omitting it prevented the initial
turn in Claude's variadic-flag launch, while Codex and Cursor still displayed the turn. Codex
requested external-read command approval in both sandbox modes; Claude and Cursor returned their
brief markers without file-read approval in the tested setups. The tables preserve the limits:
MCP parsing was tested without a fresh live Conduit identity, Codex showed no trust dialog, and
Claude's additional-directory instruction-loading result is observational rather than a loader trace.

Cursor probe caveats and side effects:

- Initial trust/`--` probes inherited the parent's `CONDUIT_SESSION_TOKEN` and `CONDUIT_MCP_ENDPOINT`; their values were never printed. Subsequent no-separator, external-read and add-dir probes explicitly removed both from the PTY child environment. Cursor displayed automatic startup of `npm exec firebase-tools@latest mcp --dir <scratch repo>` from existing user wiring. Propagation of the Conduit variables into that MCP subprocess is unverified; parent environment presence does not prove child propagation.
- Cursor attempted a `cli-config.json.<pid>.<uuid>.tmp` rename to `cli-config.json` and received `EPERM`. Metadata-only inspection found `mcp.json` length 104 with old mtime (2026-06-13 18:40 UTC), and `cli-config.json` length 2058 with mtime 2026-10-26 16:47 UTC. These are metadata observations, not byte-equality checks. No manual config edits were made. Its own config writes were accepted by the lead before the real-profile retry.
- The initial isolated-profile attempt showed `Press any key to log in...`. Automatic approval review rejected reading the real credential-state file wholesale; it was left untouched. The lead then authorized the authenticated-profile route above; credentials were not copied for Cursor.
- Probe scratch files/logs were removed and no process command line still referenced the owned scratch directory after cleanup. Actual APPDATA paths and a fresh, live Conduit MCP identity were not tested.
