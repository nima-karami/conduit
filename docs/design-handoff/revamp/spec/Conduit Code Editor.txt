This settles the code-surface question I kept re-opening. 5a already puts the terminal on #1b1e2b at 20px radius inside light Aero, so the editor uses the same panel: code is dark in both themes, matching the styles.css note, and the light-Monaco theme I was proposing is not needed. Contrast is a non-issue on ink.
Real review-view.tsx imports, italic-free 34px pill tab row, breadcrumb inside the code panel rather than as a fifth chrome band, git chip and actions right-aligned in the tab row.
Explorer sits in the 340px rail with per-language tints, changed-directory dots, and the open file selected — 5a's tree treatment, extended to depth.
